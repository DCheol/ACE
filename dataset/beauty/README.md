# Amazon_ratings(2014) Beauty Dataset

### 1. Download
Please download `Amazon_Beauty.zip` from the link below:
👉 [Google Drive Folder](https://drive.google.com/drive/folders/1FUAScpZtCmArqQS0xdrIqpFx5F7u3TaY)

### 2. Unzip & Rename
After downloading, unzip the file and **rename the extracted files** so the preprocessing scripts can recognize them properly.

1. Unzip `Amazon_Beauty.zip` to extract:
   - `Amazon_Beauty.inter`
   - `Amazon_Beauty.item`

2. Rename the files to:
   - `beauty.inter`
   - `beauty.item`

3. Place both `beauty.inter` and `beauty.item` directly into this directory (`dataset/beauty/`).
